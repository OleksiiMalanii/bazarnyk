# Bazarnyk

Шукає найдешевші **б/в товари на OLX** і ціни в **українських магазинах** (Prom, Hotline, Епіцентр, Фокстрот, MOYO, Ельдорадо, Алло), а коли знаходить щось нове або дешевше, пише тобі в **Telegram**.

```
Ти в Telegram: «пошукай мені драбину Hailo до 3000»
        │
        ▼
Список пошуків (закріплене повідомлення бота)
        │                                   │
        ▼                                   ▼
GitHub Actions, 24/7                  Розширення в браузері
магазини — як часто вибереш           OLX б/в і Алло — поки браузер відкритий
        │                                   │
        └──────────────► Telegram ◄─────────┘
```

Чому OLX і Алло через розширення: OLX не віддає результати програмам на серверах, а Алло блокує сервери GitHub. Розширення шукає з твого браузера (Chrome або Edge), як звичайний відвідувач.

Сервер, база даних і оплата не потрібні. Усе працює на безкоштовному GitHub Actions і Telegram.

## Налаштування (≈15 хвилин)

### 1. Створи Telegram-бота
1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → придумай ім'я.
2. Збережи токен, який він дасть (`123456:ABC...`). Нікому його не показуй.

### 2. Запусти хмарну частину
1. Натисни **Fork** вгорі цієї сторінки, щоб мати свою копію.
2. У своїй копії: **Settings → Secrets and variables → Actions → New repository secret**:
   `TELEGRAM_BOT_TOKEN` = токен бота.
3. Вкладка **Actions** → увімкни workflows.
4. Напиши своєму боту `/start`, потім **Actions → check → Run workflow**.
   Бот відповість твоїм chat id.
5. Додай ще один секрет: `TELEGRAM_CHAT_ID` = цей chat id.

### 3. Налаштуй Worker
Він робить відповіді бота миттєвими і потрібен для розширення. Інструкція — розділ [«Миттєві відповіді»](#миттєві-відповіді-cloudflare-worker-безкоштовно) нижче.

### 4. Встанови розширення для OLX і Алло
1. **Code → Download ZIP**, розпакуй.
2. Відкрий `chrome://extensions` (або `edge://extensions`), увімкни **Режим розробника**.
3. **Завантажити розпаковане** → вибери папку `extension`.
4. У боті натисни **⚙️ Налаштування → 🧩 Підключити браузер** і скопіюй код.
5. Натисни на значок Bazarnyk у браузері, встав код → **Підключити**.

## Як користуватися ботом

Просто напиши боту звичайними словами, що шукаєш:

- «драбина Hailo до 3000»
- «пошукай мені б/у айфон 13 не дорожче 12к»

З ШІ-фільтром бот сам зрозуміє, що шукати і за якою ціною. Без нього прибере «пошукай мені» й візьме решту як запит.

Під полем вводу є кнопки **➕ Додати пошук**, **📋 Мої пошуки** (там же видалення), **⚙️ Налаштування** і **❓ Допомога**.

У **⚙️ Налаштування** кнопками вибираєш, на яких сайтах шукати, і як часто перевіряти: кожні 30 хв, 1, 2, 5 год або **⏸ Не повторювати** (кожен пошук перевіряється один раз).

У **📋 Мої пошуки** біля кожного пошуку є ⏸ — поставити його на паузу (▶️ — відновити) і 🗑 — видалити. Слово з мінусом відкидає оголошення з ним: «драбина -книга».

У вікні розширення (іконка Bazarnyk на панелі браузера) теж видно всі пошуки: найнижчу знайдену ціну з посиланням, ⏸ пауза, 🗑 видалення і поле, щоб додати новий пошук. Число на іконці — скільки знахідок з OLX і Алло надіслано, відколи ти востаннє відкривав вікно.

Для тих, хто любить команди: `/add`, `/list`, `/del 2`, `/settings`, `/help`.

Без Worker бот відповідає протягом ~30 хвилин (так часто GitHub запускає перевірку). Щоб відповідав миттєво, налаштуй Worker нижче.

### Миттєві відповіді (Cloudflare Worker, безкоштовно)

Worker приймає повідомлення одразу, відповідає за секунду і запускає хмарну перевірку на GitHub, тому перші результати приходять за 1–2 хвилини.

1. Зареєструйся на [cloudflare.com](https://dash.cloudflare.com/sign-up).
2. У папці `worker`:
   ```bash
   npx wrangler@4.151.3 login
   npx wrangler@4.151.3 deploy
   npx wrangler@4.151.3 secret put TELEGRAM_BOT_TOKEN
   npx wrangler@4.151.3 secret put TELEGRAM_CHAT_ID
   npx wrangler@4.151.3 secret put WEBHOOK_SECRET
   ```
   `WEBHOOK_SECRET` — будь-який довгий випадковий рядок.
3. Необов'язково: [GitHub-токен](https://github.com/settings/personal-access-tokens/new) лише на свій репозиторій з правом **Actions: Read and write** → `npx wrangler@4.151.3 secret put GITHUB_TOKEN`, і назва репозиторію (`твій-логін/bazarnyk`) → `npx wrangler@4.151.3 secret put GITHUB_REPO`. Без них результати прийдуть з найближчим запуском (до 30 хв).
4. Підключи бота до Worker (адреса з кроку `deploy`):
   ```bash
   curl -X POST -H "x-setup-key: <WEBHOOK_SECRET>" https://bazarnyk.<твій-субдомен>.workers.dev/setup
   ```

На Windows у PowerShell пиши `npx.cmd` замість `npx`.

### Для родини чи друзів
Додай бота в групу й зроби його адміністратором (потрібно для закріпленого повідомлення). Як `TELEGRAM_CHAT_ID` використай id групи: напиши `/start` у групі, поки секрет не заданий.

## ШІ-фільтр (необов'язково)

Для кожного пошуку ШІ один раз складає список слів, за якими відкидається сміття: іграшки, книги, металобрухт. Наприклад, для «драбина» це будуть «книга, lego, конструктор, швелер…». Бот покаже список одразу після `/add`.

ШІ викликається один раз на пошук, а не при кожній перевірці, тому витрати мізерні.

**Варіант 1 — підписка Claude (Pro/Max):**
1. На своєму ПК виконай `claude setup-token` (потрібен встановлений [Claude Code](https://claude.com/claude-code)) і скопіюй токен.
2. Додай секрет `CLAUDE_CODE_OAUTH_TOKEN` = цей токен.

**Варіант 2 — будь-який OpenAI-сумісний API:**
1. Отримай ключ на [openrouter.ai](https://openrouter.ai/keys) (безкоштовні моделі) або [platform.deepseek.com](https://platform.deepseek.com). Сервіс визначається за ключем сам.
2. Додай секрет `AI_API_KEY`.
3. Для іншого сервісу (Groq, Google AI Studio) додай у **Settings → Secrets and variables → Actions → Variables**:
   `AI_BASE_URL` (напр. `https://openrouter.ai/api/v1`) і `AI_MODEL` (назва моделі в цьому сервісі).

Без ключа все працює, тільки без ШІ-фільтра.

## Що надсилає

- **OLX:** при першій перевірці 3 найдешевші б/в оголошення, далі лише нові оголошення від найдешевшого. До OLX-повідомлення додається найнижча ціна в магазинах для порівняння.
- **Магазини:** найнижча ціна при першій перевірці, далі лише коли з'являється ще дешевша. Товари, яких немає в наявності, пропускаються.

## Обмеження

- OLX і Алло перевіряються, лише поки браузер відкритий. Пропущене знайдеться при наступному запуску.
- Хмара на GitHub запускається раз на 30 хв, тому частіше за 30 хв магазини не перевіряються.
- Rozetka і Comfy не підтримуються: вони закриті перевіркою від ботів.
- Фільтр за назвою простий. На «драбина» може трапитися «книга Драбина», такі слова відкидай через `-книга`.
- До ~30 пошуків: список зберігається в одному повідомленні Telegram. Не видаляй і не відкріплюй його.
- GitHub вимикає розклад у репозиторії, де 60 днів не було змін. Якщо бот замовк, увімкни workflow знову у вкладці Actions.

## Розробка

```bash
npm test          # юніт-тести
npm run smoke     # живий запит до всіх магазинів (на GitHub: Actions → smoke)
```

Спільний код для хмари й розширення лежить у `extension/lib/`, бо розширення Chrome не може імпортувати файли поза своєю папкою.
